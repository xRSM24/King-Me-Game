# Soulstack

A goofy costume-pile adventure for kids (and grown-ups who still like rubber-band bows). You play **Pip**, a round pajama ghost with no hearts — only a wobbly pile of silly outfits. Bonks knock costumes off. Outfits you skip go to **King Empty**. Don't skip too many.

## The loop

1. Wander a candy-colored closet dungeon.
2. Bump a costume. When they flop, **Wear** them or **Snack** them.
3. Wear: put the outfit on. Costumes under the top one leak extra tricks. Some piles make **silly combos**.
4. Snack: take the coins. King Empty keeps that costume for the final fight.
5. The pile is short. Too many hats, and the bottom one tumbles into the King's closet.
6. Floor 6 is King Empty — a giant raincoat made of every outfit you didn't wear.

Wear-heavy runs make a weaker king and a weirder Pip. Snack-heavy runs buy Lucky Pins, then fight a bigger, goofier boss. That choice is the game.

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints (this project pins **http://127.0.0.1:43181**).

```bash
npm run build
npm run preview
```

Progress lives in the browser (`localStorage`). Stickers spend on permanent perks between runs. Today's Closet uses a shared UTC seed.

## Controls

| Action | Keys |
| --- | --- |
| Move | WASD, arrows, vim hjkl, or click a tile |
| Wait / pocket lint | Z or `.` |
| Costume power | Space or F |
| Wear / Snack | 1 / 2 |
| Pause | Esc |

On a phone, a d-pad and Power button appear.

## Costumes

Pip, Squeak, Sir Clank, Twang, Nib, Bubbles, Chili, Sir Boop — and King Empty. Each changes how you boop and bounce, not just your numbers. Buried outfits leak tricks. Together they unlock combos such as Snack Magnet, Pew Thief, and Costume Party.
